# Atribución de diseño: Relay Auth — Colorlib

Plantilla de referencia aportada por el usuario: **Relay Auth** (Colorlib, 2026).

- Autor original: Colorlib — https://colorlib.com/
- Licencia: Creative Commons Attribution 3.0 Unported — https://creativecommons.org/licenses/by/3.0/legalcode
- Archivos originales analizados: `assets/style.css` y `index.html` de `relay-auth.zip`.
- Adaptaciones: composición de dos paneles, tipografía editorial, colores verde bosque/marfil, ilustración en CSS sobre ventas y componentes React del inicio de sesión. Los estilos del ERP se han armonizado con el diseño.
- La autenticación y la persistencia se mantienen en Supabase; no se usa el JavaScript de demostración de Colorlib, ni se habilita el registro público de usuarios.

La atribución también se muestra en el pie del inicio de sesión.
